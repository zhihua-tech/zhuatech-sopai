# 知华 SOP 执行核验

> 作业指导书要能落到现场，而不只是放在文档库里。

本项目由上海如静知华信息科技有限公司提供公开源码，面向生产、仓储、质检和服务团队的标准作业执行记录。官网：[https://www.zhuatech.cn/](https://www.zhuatech.cn/)。

## 从版本到整改

```text
指导书起草 ──独立审核发布──► 现场执行
                                  │
                          逐步骤本地核验
                           ├─ 无缺失 ─► 独立审核归档
                           └─ 缺失/未知步骤 ─► 偏差 ─► 整改 ─► 重新核验
```

- 指导书维护标准步骤、关键步骤、适用区域和版本；关键步骤必须存在于标准步骤中。
- 执行记录关联已发布版本，填写已完成步骤与现场观察。
- 本地核验逐项比较步骤，区分关键步骤缺失与一般缺失，保留核验及偏差流水。
- 有偏差不得直接归档，须填写整改措施、重新核验通过后由非创建人审核。
- H5 业务端和后台管理端包含权限、审计、租户隔离、附件、幂等和导出。

示例：指导书要求“登记；核验；复核”，关键步骤为“核验”。现场只登记了“登记；复核”时，系统生成高风险偏差；补做核验并再次通过规则检查后才能归档。完整成功与拒绝路径写在 `backend/src/test/resources/acceptance.json`。

### 分析能力边界

`backend/src/main/java/cn/zhuatech/sopai/InsightProvider.java` 是核验接口，默认实现使用**本地可解释规则，不调用外部 AI 模型**。企业可接入国内模型辅助识别自然语言步骤，但现场事实、关键步骤和最终签核必须由责任人确认。当前版本不包含视频识别或设备自动采集。

## 安装与测试

后端 Java 21 / Spring Boot 4 / MySQL 8.4，前端 Vue 3 H5。使用 `.env.example` 配置数据库与四种角色强密码：

```bash
docker compose up -d --build
sh scripts/test.sh
```

默认业务界面 `http://127.0.0.1:8088`，管理端 `/admin`。脚本运行后端 H2/MySQL 兼容测试、前端单测和生产构建，CI 配置 MySQL 复测。通过 `GET /api/catalog` 查看字段和动作，通过记录动作接口执行 `analyze`、`correct` 和 `finalize`。生产需补足培训、现场设备及文件留存制度验证。
